# Term Project Repository Submission Guideline

This document provides instructions for preparing and submitting your term project using a GitHub repository.

The objective of this repository is to **showcase** your term-project publicly online.

This is not a complete guideline; you are encouraged to search and use AI tools for GitHub operations and Markdown formatting assistance.

## Some Useful Examples

- https://github.com/irenezh1016/Project-Wildfire

## Steps 

- If you do not have an account yet, create your GitHub account at https://github.com.
- Create a new repository:
  - Repository name: a short and clear `ProjectName` (e.g., `InflowPrediction`)
  - Initialize with: `README.md`
  - Visibility: `Public`
  - Your repository will now contain a default `README.md`.
- Write your `README.md` (Markdown):
  - Your `README.md` is the main documentation for your project.
  - You may reuse text from your term-project report, but this should be a concise version. Make sure the `README.md` is not too long or overly detailed.
  - Markdown is simple, and you only need a few basic features. If needed, refer to https://www.markdownguide.org/basic-syntax/.
  - On GitHub → your repository → you can edit/preview `README.md` directly in the browser.

## Recommended README Structure

This is a typical structure. You may adjust it or use your own outline aligned with your term project report.

```markdown
# Project Title

## Introduction
Describe the problem your project addresses and explain why it matters.

## Methodology
Explain your approach, tools, models, algorithms, or theoretical framework.

## Data
Discuss the dataset(s), data sources, preprocessing methods, and limitations.

## Results
Present figures, tables, or summary statistics.  
Include plots using the `/figures` folder.

## Discussion
Interpret your results. What do they mean? What are the insights?  
What would you improve with more time?

## References
List academic papers, datasets, and online tools used in your project.
```

Create a `/documents` folder and add your term-project presentation file and project report PDF file:

- `documents/final_report.pdf`
- `documents/slides.pptx`

## Commit and Push Your Work

Before finalizing your repository, ensure it includes:

- An updated `README.md`
- All figures inside the `/figures` folder
- Your final report and slides inside the `/documents` folder

If you edit files directly on GitHub.com, your changes are saved when you commit in the web interface.

If you are working on your own device (using Git), follow these steps:

1. Commit your changes  
2. Push your commits to GitHub  
3. Open your GitHub repository in a web browser  
4. Verify that:
   - All folders appear correctly  
   - Images load properly in the `README.md`  
   - PDF and PowerPoint files open without issues  
   - Any code files are accessible
